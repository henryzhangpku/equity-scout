A frontier model inside the firm's controls
Nothing structural: the model only fills the spec and writes cited prose
  1. Translate. The model fills a whitelisted JSON spec. Unknown fields, operators, units or industries are refused with a reason; anything the schema cannot express is listed as not screened.
  2. Screen. Code applies each condition in order and records how many names enter, pass, fail and lack data. Gaps stay gaps.
  3. Rank. A weighted mean of percentile ranks, ties broken by market cap then ticker.
  4. Explain. For the top names the model gets the computed numbers, the filing text and recent news headlines and summaries; each claim must quote one of them. Code keeps a claim only if the quote is found verbatim and every number in the claim is in the quote; with fewer than two surviving claims the verdict is not enough evidence.
